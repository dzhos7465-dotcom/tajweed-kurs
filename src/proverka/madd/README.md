# Контрольная и тренажёр по мадду

Общее описание, движок и порядок пересборки — в `src/proverka/README.md`.

- `data.py` — задания: `tasks('k')` контрольная (66 мест), `tasks('t')` тренажёр (короткая версия для урока, 45 мест; сокращение — словарь `keep` в конце `tasks()`).
- `madd.py` — автоматическое определение вида мадда в аяте (остановка только в конце аята) — для проверки.
- `verify.py` — сверка всех ответов: должно быть «ВСЁ ВЕРНО».
- `build.py` → `proverka/madd-kontrolnaya.html`, `proverka/madd-trenazher.html`.
- Ключ хранения ответов контрольной: `madd-kontrolnaya-v1` (по умолчанию в движке).
