## Как устроено

```
src/proverka/
  engine/          общий движок — один на все работы
    template.html  страница: экраны, задания, оценка, итог, пересдача
    common.py      текст аятов, места в аятах (P, C, A), сборка build_work(...)
    tk.py          корпус, сверка слов, текст hafsData_v18, шрифт KFGQPC
  do-madda/        работа: data.py (задания), verify.py (проверка ответов), build.py
  madd/            работа: data.py, madd.py (автоопределение мадда), verify.py, build.py
```

## Пересборка работы

```
cd /tmp && GIT_LFS_SKIP_SMUDGE=1 git clone -q --depth 1 https://github.com/risan/quran-json
cd src/proverka/<папка работы>
python3 verify.py   # каждый ответ вычисляется заново по тексту аята: должно быть «ВСЁ ВЕРНО»
python3 build.py    # пишет готовые файлы сразу в proverka/
```

## Новая работа

1. Скопировать папку `do-madda/` под новым именем (например `dva-sukuna/`).
2. Переписать `data.py` (задания) и проверку в `verify.py`. Движок не трогать.
3. В `build.py` — имена файлов, заголовки и **новый `key`** (ключ хранения ответов, иначе ответы смешаются с другой работой).
4. `verify.py` → `build.py` → добавить карточки на `proverka/index.html` (место отмечено `<!--PROVERKA-->`) и строку в таблицу выше.

## Типы заданий (`kind`)

- `label` — у каждого места выбрать ответ из `opts` (`P(сура, аят, слово, ответ, hl=буквы)`).
- `pickWord` / `pickAya` — отметить подходящие карточки (`C(...)` / `A(...)`).
- `tap` — нажать на слова в суре (`targets`); с `opts` — потом выбрать ответ для каждой отметки.
  `neutral` — места, которые не засчитываются и не штрафуются (например, танвин в конце аята при остановке).
- Объяснения ответов: `gen` у работы (общие) или у задания (только для него).

## Правила (решения преподавателя)

- Контрольная: ответы только после «Завершить», одна попытка, ответы хранятся на телефоне ученика, никакие данные никуда не отправляются (ученик присылает скриншот итога).
- Баллы: +1 за место, −1 за лишнюю отметку (не ниже 0 за задание), итог из 100.
  Оценки: 5 — от 95, 5− — от 90, 4 — от 80, 4− — от 75, 3 — от 65, 3− — от 50, ниже 50 — 2. Сдано от 50.
- Кнопки «Перепройти» в контрольной нет: после разбора ученик знает ответы. **Пересдача** — та же ссылка с `#peresdacha` в конце; преподаватель отправляет её лично. Прошлая попытка стирается, пересдача тоже одна.
- `#reset` в конце ссылки — полный сброс (для проверки преподавателем).
- Тренажёр: ответы сразу, «Ещё раз» у каждого задания, «Пройти заново» в конце.
- Текст аятов строго как в мусхафе (hafsData_v18), шрифт KFGQPC встроен, светлая тема закреплена.
